# Gradient Descent & Multivariable Calculus Extension

## Project Overview
- (June 2026 - Implementation): Developed a Java-based linear regression tool using AP Calculus AB single-variable optimization to model highway traffic data.
- (August 2026 - Tools Extension): Self-studied Vector Calculus to re-analyze the optimization trajectory as a 2D Gradient Field (∇f).

# Convergence & Limitations
- The algorithm requires a sufficiently small learning rate (η) to prevent divergence. On a paraboloid surface (unsure about other shapes), convergence slows significantly near the local minimum as the gradient magnitude approaches zero (||∇f|| ≈ 0), illustrating the classic vanishing gradient behavior in basic optimization
