# Gradient Descent & Multivariable Calculus Extension

## Project Overview
- (June 2026 - Implementation): Developed a Java-based linear regression tool using AP Calculus AB single-variable optimization to model highway traffic data.
- (August 2026 - Theoretical Extension): Self-studied Vector Calculus to redefine the optimization trajectory as a 2D Gradient Field and evaluated convergence behavior via 2D Divergence ($\nabla \cdot \mathbf{F}$).

# Limitations & Mathematical Analysis

## Convergence & Limitations
- The algorithm requires a sufficiently small learning rate (\(\eta \)) to prevent divergence. On a paraboloid surface, convergence slows significantly near the local minimum as the gradient magnitude approaches zero (\(\Vert{}\nabla f\Vert{} \approx 0\)), illustrating the classic vanishing gradient behavior in basic optimization
